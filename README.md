  - Apuntes_Biofisica_Clase_02_Metabolismo.md
- **Apuntes_PDF/**: Apuntes listos para descargar, imprimir o leer en formato PDF (.pdf).

- **Archivos de Ita y Resumenes/**: Material complementario de cursadas anteriores.
